# 이전 웨딩 프로젝트

앞으로의 개발 저장소는 `YangSaekyul/marrycheck` 하나입니다. 실행 앱은 저장소 루트의 `src/`입니다.

| 폴더 | 보존 내용 |
| --- | --- |
| `marry-check` | Firebase 기반 이전 프론트·백엔드. 맥북에만 있던 17개 커밋 포함 |
| `wedding-mate` | 카카오 로그인·Prisma 기반 이전 앱과 미커밋 수정 3개 |
| `our-wedding-mate` | 이전 협업 플래너 앱 |

원래 커밋 이력은 main의 병합 부모와 `legacy/*-20261117` 브랜치에서 조회할 수 있습니다.
이 폴더는 소스 참고용이며 루트 앱의 TypeScript 빌드 대상에서 제외합니다.
개별 앱이 하나의 서비스로 기능·인증·DB까지 합쳐진 상태를 의미하지 않습니다.
이전 코드의 DB 마이그레이션이나 배포 스크립트를 운영 환경에서 실행하지 마세요.
환경 파일, 의존성, 빌드 결과물과 로컬 사용자 DB는 가져오지 않았습니다.
파일별 원본 해시는 `../docs/consolidation-2026-11-17.json`에 기록했습니다.
